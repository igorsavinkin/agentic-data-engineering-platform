# Architecture Communication — AI Data Platform

Visual architecture documentation for the AI Data Platform, covering system structure, data flows, and component responsibilities from source ingestion through serving.

## Contents

| File | Format | Description |
|------|--------|-------------|
| `container-view.dot` / `.svg` | Graphviz DOT | System landscape: services, Kafka topics, data stores, boundaries. Solid lines = implemented (M0–M13), dashed = future (M14+). |
| `data-flow.dot` / `.svg` | Graphviz DOT | Linear data flow: external sources → ingestion → Kafka → processing → data lake → warehouse → Airflow → Gold → serving. |
| `reading-notes.md` | Markdown | How to read both diagrams, evidence links to code, milestone status, component inventory. |
| `architecture-communication-plan.md` | Markdown | Audience, messaging hierarchy, scope, and assumptions for the diagram set. |
| `delivery-summary.md` | Markdown | Package overview with current implementation status table and next steps. |

## Current state (as of TASK-DOCS-PLATFORM-INVENTORY-M13)

Milestones 0–13 implemented: event platform (Kafka), processing pipeline, data lake (Bronze/Silver Parquet on MinIO), PostgreSQL warehouse (8 tables, Alembic migrations), 5 source adapters, Airflow orchestration (4 DAGs), FastAPI serving layer (13+ endpoints), Kubernetes/Helm deployment, observability (Prometheus/Grafana/OpenTelemetry/Jaeger), LangGraph Data Engineer Agent (4 read-only tools), failure engineering (replay, idempotency, DLQ), and performance testing (100/500/1000 eps benchmarks).

Comprehensive architecture inventory: `docs/architecture/platform-inventory-m13.md`.

Next: M14 (Terraform / AWS), M15 (Production Polish).

## Rendering

DOT files can be rendered with Graphviz:

```bash
dot -Tsvg docs/architecture-communication/container-view.dot -o docs/architecture-communication/container-view.svg
dot -Tsvg docs/architecture-communication/data-flow.dot -o docs/architecture-communication/data-flow.svg
```

Pre-rendered SVGs are included in this directory. Note: SVGs require regeneration after DOT source updates when Graphviz is available.
